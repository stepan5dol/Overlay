# Раздача Overlay: DMG и открытый код на GitHub

## Зачем

Сейчас приложение работает **только на этой машине**. В бандл при сборке
вшиты путь к репозиторию и путь к `python` из чужого venv; модель
CustomVoice берётся из папки `qwen3-tts-apple-silicon`, которой у других
нет; библиотека `mlx-audio` требует правки в `site-packages`, сделанной
руками. На другом компьютере не запустится ничего.

Цель: собрать DMG, который открывается двойным щелчком, и выложить
исходный код так, чтобы сборка воспроизводилась не только у автора.

## Что мешает сегодня (проверено)

| препятствие | где | следствие |
|---|---|---|
| путь к репозиторию и к python вшиты при сборке | `app/build.sh`, ключи `ThoriumRepoRoot`, `ThoriumPython` | вне этой папки приложение не находит конвейер |
| путь к модели CustomVoice захардкожен | `src/book.py`, `CUSTOM_VOICE_MODEL` | готовые голоса работают только здесь |
| правка `mlx-audio` меняет `site-packages` | `patches/enable_icl_encoder.py` | переустановка библиотеки ломает клонирование |
| правка `tokenizer_config.json` сделана в чужом каталоге модели | `qwen3-tts-patched/` | не переносится и не воспроизводится |
| нет сертификата Developer ID | в системе только «Apple Development» | Gatekeeper заблокирует DMG у всех, кроме автора |
| модели 2.9 ГБ и 4.2 ГБ | кэш HuggingFace | в образ не кладутся |

## Принятые решения

**Ничего не скачивается само.** Загрузка начинается только по явному
действию: пользователь выбирает голос — приложение сообщает, какая модель
нужна и сколько весит, и качает лишь после подтверждения. Отсюда следует,
что интерпретатор и библиотеки должны лежать **внутри** приложения:
доставлять их молча при первом запуске — та же скрытая загрузка.

**Два набора голосов — две модели**, это остаётся:
образцы (`vakhshtayn`, `linda_johnson`, `bryan_ness`, `meredith_hughes`)
работают на `Qwen3-TTS-12Hz-1.7B-Base-8bit`, готовые голоса — на
`1.7B-CustomVoice`. В списке голоса помечаются: модель на месте или её
предстоит скачать.

## Работы по порядку

### 1. Оторвать код от этой машины

- `app/build.sh`: убрать `ThoriumRepoRoot` и `ThoriumPython`. Конвейер и
  интерпретатор кладутся внутрь бандла, пути вычисляются от
  `Bundle.main`.
- `src/book.py`: `CUSTOM_VOICE_MODEL` заменить на идентификатор
  HuggingFace (`mlx-community/Qwen3-TTS-12Hz-1.7B-CustomVoice-8bit`)
  вместо локальной папки. **Проверить на месте**: нужна ли скачанной
  версии та же правка `tokenizer_config.json`, что понадобилась
  локальной. Если нужна — применять её в памяти при загрузке, а не
  править файлы.
- Правку `mlx-audio` перевести из «меняем `site-packages`» в
  monkey-patch, применяемый при импорте (`src/icl_patch.py`, вызывается
  из `narrate.py` до `load_model`). Файлы библиотеки больше не трогаем.
- Отдельным шагом: отправить эту правку в upstream
  [Blaizzy/mlx-audio](https://github.com/Blaizzy/mlx-audio) — ошибка там
  настоящая, `encoder_config` не разбирается, из-за чего ICL молча
  выключается у всех.

### 2. Положить рабочее окружение внутрь приложения

- Взять самодостаточный интерпретатор (python-build-standalone) и
  поставить в него `mlx-audio`, `ebooklib`, `beautifulsoup4`, `soundfile`,
  `numpy`, `tqdm` через `uv pip install --python`.
- Разложить в `Overlay.app/Contents/Resources/`: `python/`, `src/`,
  `refs/`.
- `ffmpeg` нужен для сборки аудио и для темпа: положить один статический
  бинарник туда же, вызывать по пути из бандла, а не из `PATH`.
- Скрипт `app/bundle_runtime.sh` делает это воспроизводимо; версии
  фиксируются в `app/requirements.lock`.

### 3. Загрузка моделей по нажатию

- `src/models.py`: `status()` — что уже в кэше; `download(repo_id)` —
  качает с выводом процентов в stdout, чтобы окно рисовало полосу.
- В окне рядом с каждым голосом пометка: «готов» или «нужно скачать
  2.9 ГБ». По нажатию — подтверждение и загрузка, с возможностью
  остановить.
- Синтез не стартует, пока модель не на месте; вместо молчаливой ошибки —
  явное предложение скачать.

### 4. Подпись и нотаризация

Есть только «Apple Development», для раздачи нужен **Developer ID
Application** (платное членство в Apple Developer Program).

- Если членство есть: подпись с hardened runtime, `xcrun notarytool
  submit --wait`, `xcrun stapler staple` — и приложения, и DMG.
  Понадобится послабление `com.apple.security.cs.allow-jit` для MLX и
  разрешение на запуск вложенного интерпретатора.
- Если членства нет: собираем неподписанный DMG и пишем в README, как
  снять карантин (`xattr -dr com.apple.quarantine`). Работает, но часть
  людей отвалится на этом шаге.

### 5. DMG

- `app/make_dmg.sh`: `create-dmg` (или `hdiutil`) с фоновой картинкой,
  иконкой тома и ссылкой на `/Applications`.
- Имя: `Overlay-<версия>-arm64.dmg`. Только arm64 — колёса `mlx` под
  Intel не собираются.

### 6. Публикация

- Лицензия на код: MIT. Отдельно указать, что модели Qwen3-TTS и
  библиотека `mlx-audio` идут под своими лицензиями.
- `README.md` на английском (для GitHub) + `README.ru.md`.
- Происхождение образцов голоса — уже описано в `refs/README.md`,
  перенести в основной README: LJSpeech и LibriVox — общественное
  достояние.
- Раздел об ответственности: инструмент клонирует голос: чужой голос —
  только с разрешения владельца.
- `.github/workflows/release.yml` на `macos-14`: собирает бандл и DMG по
  тегу. Подпись и нотаризация — только если в секреты положены
  сертификат и ключ App Store Connect.

## Требуют твоего решения

1. **Голос Вахштайна в публичном репозитории.** Это голос живого
   человека, а рядом лежит код клонирования. Рекомендую убрать
   `refs/vakhshtayn.*` в `.gitignore` и подобрать для русского языка
   чтеца LibriVox из общественного достояния; локально у тебя всё
   останется как есть. Решение твоё, не техническое.
2. **Платное членство Apple Developer** — от этого зависит, будет DMG
   открываться двойным щелчком или через обход карантина.
3. **Имя проекта.** `Overlay` — рабочее, придумано вместо занятого
   `Thorium`. Для публичного репозитория, возможно, стоит другое.

## Как проверить, что получилось

1. `app/bundle_runtime.sh && app/build.sh && app/make_dmg.sh` — на выходе
   `Overlay-*.dmg`.
2. Смонтировать образ, перетащить в `/Applications`, запустить.
3. Проверить отсутствие следов этой машины:
   `strings Overlay.app/Contents/MacOS/Overlay | grep stepandolzhenko` —
   пусто; в `Info.plist` нет `ThoriumRepoRoot` и `ThoriumPython`.
4. Временно переименовать `~/.cache/huggingface` — приложение должно
   сказать «нужно скачать», а не упасть, и **не начать качать само**.
5. Скачать модель нажатием на голос, озвучить главу
   (`--only 21 --limit-chunks 5`), получить EPUB.
6. Настоящая проверка переносимости — запуск на другом компьютере, где
   нет ни `qwen3-tts-apple-silicon`, ни правленого `site-packages`.
