# Thorium 2.0

Книга → аудиокнига. Часть 1: довести озвучку до нормального качества.

## Состояние

Диагностика дефектов в существующей озвучке
(`~/qwen3-tts-apple-silicon`, 14.9 ч аудио, 429 глав).

- `src/find_stutter.py` — поиск повторов (заиканий) по нормированной
  корреляции сырой волны. Спектральное сходство для этого не годится:
  живая речь периодична и даёт 45 ложных срабатываний в минуту.
- `src/calibrate.py` — нарезка клипов по уровням сходства, чтобы порог
  ставился на слух, а не наугад.
- `src/extract.py` — извлечение главы из PDF (часть 2, отложено).
- `src/analyze_audio.py` — сегментация по вставленным паузам.
  На имеющемся аудио неприменима: пауз 0.8 с в нём нет, то есть
  сгенерировано не тем кодом, что лежит в том репозитории.

## Не подтверждено

Гипотеза «инлайновые теги дробят фразу» (`get_text(separator=' \n. ')`)
на реальном звуке не подтвердилась и снята.
